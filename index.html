How to read this

Controls: drag a source sphere to move it; click (tap) either landscape to drop the test object there; drag empty space to orbit; scroll (pinch) to zoom.

Left landscape: height = the potential (V or φ) at each point. The sources alone set it. Nothing you do to the test object changes it.

Right landscape: height = the potential energy U = qV (or mφ) that this test object would have at each point. It is the left landscape multiplied by q, so it stretches, flattens and even flips as you change q.

The test object rolls on the right landscape, because the force is the downhill slope of U: F = −∇U. The cone on the left is a probe that reads the potential at the same spot.

The flat outline under each landscape is the zero reference (V = 0, i.e. far away). Heights are compressed near the sources so the peaks stay on screen.
